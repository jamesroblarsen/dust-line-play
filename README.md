# Dust Line

A co-op escape across the desert by train for 2 to 4 players (online with a join code). Windows only for now.

## ⬇ [Download Dust Line for Windows](https://github.com/jamesroblarsen/dust-line-play/releases/latest/download/DustLine-windows.zip)

About 90 MB. It's free, and you don't need an account.

1. **Unzip** the whole folder. Don't run the game from inside the zip.
2. Double-click **DustLine.exe**.
   If Windows says *"Windows protected your PC"*, click **More info → Run anyway**. The game isn't code-signed.
3. In the lobby pick **Single player**, **Host** or **Join**.

## Play together on the same Wi-Fi

No internet or account needed.

1. Both of you download and unzip the game.
2. One player clicks **Host** (under *Same network*).
3. The other player waits a moment: the host's game appears under **Games on your network**. Click it.

If Windows Firewall asks about DustLine.exe, tick **both** boxes (Private and Public) and click **Allow**. Do this on both PCs.

If the game doesn't show up after a few seconds, check that both PCs are on the same Wi-Fi (not a guest network). You can also type the address shown on the host's screen (like `192.168.1.23`) into the **IP** box and click **Join**.

## Play together from different houses

Easiest: one player clicks **Host online** and sends the 6-letter join code (it's copied for you). The other types it and clicks **Join with code**. This works between any two houses, with no port forwarding, IP addresses or firewall setup. Both players need internet.

## Controls

| Key | Action |
|---|---|
| Mouse / WASD | look / move |
| Shift / Space / C | run / jump / crouch |
| E / G | use / drop |
| 1 / 2 / 3 | train: go / creep / brake (in the cab) |
| L | flashlight |
| Click the window | capture the mouse |
| Esc | settings (and releases the mouse) |
| V | third person |
| Hold T | talk (proximity voice) |
| P | pause for both players |

## Older versions

Every build stays on the [Releases page](https://github.com/jamesroblarsen/dust-line-play/releases). Both players need the **same version** to play together.
